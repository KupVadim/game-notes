## Краткая суть

- **Суть:** разбор настроек Moza R9 для AC Rally — разъяснение параметров и практические значения.
- **Цель:** дать понятные значения и объяснения, чтобы получить сбалансированную отдачу руля без «зернистости».

## Основные настройки — смысл и польза

- `Steering angle / Lock` — физический предел поворота руля; рекомендуется синхронизировать с настройками игры или выбрать единый lock (например, 540°/900°).
- `Max output torque` / `Force Feedback Intensity` — рекомендуемая рабочая зона для ралли: ≈8–9 Nm.
- `Natural damping` — весомость руля; разумный диапазон 15–25% (часто 20%).
- `Natural friction` — постоянное сопротивление; начальные значения ~90% (регулируйте по ощущениям).
- `Natural inertia` — инертность руля; автор рекомендует ≈135.
- `Wheel spring strength` — не рекомендуется для реалистичности (оставлять 0).

## Продвинутые настройки — примечания

- `FFB interpolation` — сглаживает высокочастотный шум, но смазывает детали; включать только при необходимости.
- `FFB center dead zone compensation` — использовать, если есть заметная «мертвая зона» в руле.
- `Speed dependent damping` и `Game damping` — подбирать аккуратно, чтобы не «онеметь» мелкие эффекты.
- `Temperature control` — следить за нагревом мотора у DD-рулей; ПО может автоматически снижать силу.

## Практический чеклист — перед заездом

- Откалибруйте руль и отключите `Wheel spring`.
- PitHouse: `Max output torque = 9 Nm`, `Natural damping = 20%`, `Natural friction = 90%`, `Natural inertia = 135`, `FFB interpolation = 0`.
- В AC Rally: `Gain = 90–100%`, `Game damper` — подбирается под ПО, синхронизируйте `steering lock`.

```ini
# Пример конфигурации (PitHouse)
max_output_torque = 9  # Nm
force_feedback_intensity = 100
natural_damping = 20
natural_friction = 90
natural_inertia = 135
ffb_interpolation = 0
low_eq_10hz = 110
eq_15hz = 130
eq_25hz = 120
eq_40hz = 100
eq_60hz = 100
ffb_curve = linear
```

!!! warning
    Не используйте `wheel spring strength` для «реализма» — это искусственный эффект, который искажает поведение руля.

## Итог — коротко

- Ограничьте `Max torque` до ≈9 Nm; отключите `Wheel spring`.
- Держите `Natural damping` ≈20% и `Natural friction` ≈90%.
- Повышайте low-frequency EQ осторожно — значения выше ~40% могут вызвать grainy; при шуме включайте `FFB interpolation`.
- Синхронизируйте `steering lock` между PitHouse и игрой или используйте единое значение.

  - Практическая польза: повышая low-end вы усиливаете «большие удары» от неровностей; повышая high-end — детали дорожного покрытия.

- Рекомендованные уровни (автор):

- `10 Hz` — `110%` → усиливает крупные удары, полезно для понимания контакта с поверхностью.
- `15 Hz` — `130%` → дополнительные крупные толчки; осторожно — может привести к «grainy».
- `25 Hz` — `120%` → средний диапазон ударов.
- `40 Hz` — `100%` → критичное значение: автор поднял до `40%` в другом параметре; тут держит нейтрально.
- `60 Hz` — `100%` → микровибрации/информативность.

- Проблема «grainy vibration» и решение:
  - Симптом: при повышении low/medium диапазонов появляется жёсткая, «зёрнистая» вибрация.
  - Причина: игра/ПО плохо фильтрует частоты или аппаратный шум.
  - Решение: понижать проблемный диапазон (напр., <50%), или включать `FFB interpolation` для сглаживания, но помните — интерполяция смывает детали.

## :scroll: Базовая FFB кривая (FFB Curve)

- `Linear` — зачем и когда:
  - Смысл: равномерное распределение силы по углу руля.
  - Причина: простота и предсказуемость; изменение кривой меняет силу в центре/вне центра.
  - Практическая польза: оставить `linear` для начала, менять только при явной необходимости под конкретную модель руля/игру.

## :video_game: Настройки в AC Rally (In-game) — ключевые параметры

- `Gain`:
  - Смысл: общий множитель силы FFB внутри игры.
  - Практическая польза: автор использует `90%` (≈8.1 Nm), часто повышает до `100%` при использовании перчаток или привыкании.

- `Minimum / Maximum force`:
  - Смысл: границы силы, выдаваемой игрой.
  - Практическая польза: автор не заметил разницы между `0` и `15` на `minimum` — возможно несущественно для современных реализаций.

- `Game damper`:
  - Смысл: внутриигровое демпфирование (добавочный эффект к PitHouse).
  - Практическая польза: автор настроил PitHouse DVB на `100%`, получая точное соответствие; в игре держит тот уровень, который комфортен (в примере ≈20% эквивалент).

- `Steering lock` (в игре):
  - Смысл: дублирует настройку lock в PitHouse — нужно синхронизировать обе части для симметрии.
  - Практическая польза: менять одновременно в ПО и игре, если хотите аутентичность по машинам.

## :bulb: Типичные рекомендации — что люди советуют и почему (оценка надёжности)

- Часто рекомендуют:

- Использовать аутентичные steering lock по машинам (надежность: высокая — улучшает соответствие реальности).
- Ограничивать torque до `8–9 Nm` (надежность: высокая — предотвращает излишнюю нагрузку и даёт рабочий диапазон).
- Включать `natural friction` и `inertia` для «тяжести» (надежность: средняя — субъективно, может утомлять).

- Хаки / временные решения:

- Использование `wheel spring strength` для быстрого центрирования — костыль (эффект неаутентичный).
- Повышение low-frequency EQ до 50%+ без фильтрации — часто вызывает grainy (рискованный прием).

## :warning: Риски, ограничения и спорные моменты

- Grainy vibration при повышении низких частот — симптом: резкая/шумная отдача; решение: уменьшать диапазон или включать `FFB interpolation`.
- Перегрев мотора DD-руля — следите за `temperature control`; длительные сессии могут понизить FFB автоматически.
- `Hands-off protection` и `Wheel spring` изменяют естественное поведение — использовать только при явной необходимости.
- Различия железа: рекомендации автора зависят от Moza R9; другие базы (Fanatec, Simucube и т.д.) дадут другие оптимумы.
